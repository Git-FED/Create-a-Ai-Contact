# 08 — FED-OS Footer

The public footer is organized into Explore, Contact, Media, Support, and Community columns.

## Public footer links

- Explore: FED-OS ecosystem, membership landing page, storefront, and Whop landing page
- Contact: general, support, business, and careers mailboxes
- Media: official articles, blog, GitFed Blog, and artwork
- Support: Patreon, Buy Me a Coffee, and the page support options
- Community: public Discord invite, official Bluesky profile, X advertising profile, and the Private Communities eligibility page

Facebook is intentionally omitted from the footer per the supplied content. The personal Substack is also omitted because it is not an official public FED-OS destination.

## Restricted destinations

The private Matrix URL is not present in the main footer. Visitors must open `private-communities.html`, confirm they are 18 or older, and select one of the eligible countries: Canada, Switzerland, Russia, Iran, Somalia, or Turkmenistan. Only then is the Matrix link revealed.

This is a client-side disclosure gate, not a replacement for authentication, identity verification, geolocation, access control, or legal review. Apply server-side controls where the destination requires enforceable restrictions.
